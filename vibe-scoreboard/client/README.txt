Blue3 共享录分客户端 1.3.0 - Windows 10/11 64 位

1. 将 ZIP 完整解压，双击 Blue3-ScoreEntry.exe。
2. 页面左上角显示“客户端 1.3.0”。填入服务器地址和录分码，点击连接。
3. 选择已有赛季及本场选手，填写每人的半庄数和分数。
4. 本客户端的新增成绩固定使用 rate 1，页面不再提供倍率输入。
5. 所有人分数合计必须为 0。提交后看到成功及记录编号，即已入库。
6. 下一场点击“新建下一场”；结束时点击右上角“退出客户端”。

客户端不提供新增赛季或新增选手的功能。
“增加录分行”仅用于在本场选择已有选手。名单维护由主机管理员操作。
此版本只更新远程客户端，不需要更改服务器程序、接口或数据库。

更新前，请先确认当前录分已提交，并在旧页面右上角点击“退出客户端”，
再启动新版 EXE。旧版仍运行时，新版会提示退出旧版，避免继续打开旧界面。

同一场由一名录分者统一提交，避免重复录入整场。
网络中断后请使用“重试上次提交”；已确认入库的内容不会重复写入。
升级前已有的未确认提交会按原内容重试，确认后新录入的成绩使用 rate 1。

服务器地址由主机管理员提供。局域网示例：http://192.168.1.100:8766。
跨网络连接时，请使用管理员提供的 HTTPS 或 VPN 地址。
录分码由管理员单独提供，本压缩包不含录分码。
主机关机、休眠或断网期间无法连接。主机应保持共享服务器和所需网络通道运行。

客户端设置与未确认记录默认保存在 %APPDATA%\Blue3-ScoreEntry。
客户端不保存服务器数据库，也不保存录分码。可用 --data-dir 指定设置目录。
