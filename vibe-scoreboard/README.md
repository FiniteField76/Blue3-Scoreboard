# Vibe Scoreboard

本地运行的比赛记分工具. 建立多场比赛, 在比赛下记录三人对局, 输入点数、chip 和额外分自动计算成绩; 也可以建立多人对局, 仅输入基础分和 rate. 支持比赛范围筛选、技术统计、对手胜率与分数流向查询、高清走势图导出, 以及 Excel / CSV 批量导入. Python 3.10+, 无第三方 Python 依赖, 无需联网.

## 启动

完整解压 ZIP 后, Windows 双击 `start.bat`, macOS / Linux 在终端运行 `bash start.command`. 也可以进入项目目录运行:

```bash
python app.py
# macOS / Linux 可使用 python3 app.py
```

浏览器自动打开 `http://127.0.0.1:8765`. 使用期间保持启动窗口运行, 按 Ctrl+C 停止服务. 不要直接打开 `static/index.html`. 若端口无法使用, 可以运行 `python app.py --port 8000`, 然后访问 `http://127.0.0.1:8000`.

本版本只在本机运行. 在另一台电脑使用时, 将完整程序文件夹及需要的 `data` 文件夹复制过去, 安装 Python 3.10+, 在那台电脑启动程序, 再访问其自己的 `127.0.0.1` 地址.

初次启动有三位占位选手和一场空的"默认比赛". 在选手管理中改名或添加选手, 在比赛管理中建立或修改比赛, 即可开始.

## 比赛管理与统计范围

在"比赛管理"中点击"建立比赛", 输入比赛名称和可选备注. 每场比赛卡片显示其对局数量、参赛人数与当前领跑者. 点击"新建对局", 录分窗口自动选择这场比赛; 点击"查看本场统计", 查看仅包含这场比赛的排行榜和走势.

页面上方的比赛选择支持批量勾选. 所选比赛与日期范围共同筛选排行榜、对局记录、走势、技术统计和导出. "汇总全部比赛"可以恢复全部比赛范围. 日期设置保留. 比赛和走势图选手选择在当前页面保留, 刷新恢复全选.

已有对局自动归入"历史比赛", 原有分数、点数、chip、rate 与时间保留. 在"对局记录"中勾选对局, 点击"移动到比赛", 可以批量调整归属, 无需重新录入. 对局编辑窗口也可以修改所属比赛.

比赛可以改名或修改备注, 历史对局和导出同步显示新名称. 删除比赛会在确认后删除其中的完整对局及其成绩, 选手名单保留. 若确认期间比赛或对局变化, 删除会被拒绝, 请重新确认.

## 点数自动计分

1. 点击"记一局", 选择所属比赛和三位不同的选手.
2. 输入三人的整数点数和整数 chip. 没有 chip 或额外分时填写 0.
3. 三人 chip 必须相加为 0. **不校验点数之和是否为 1050**.
4. 名次只按点数确定, chip、击飞赏和额外分均不影响名次. 第一、二名同点数时自动平分第三名输掉的名次分. 第二、三名同点数时沿用原算法, 选择两人的计分先后; 三人同点数也沿用原算法选择计分先后. 计分先后不影响技术统计中的并列名次.
5. 某人点数为 0 时, 点击保存会弹出"击飞赏归属", 选择本局另一位玩家获得这 10 分. 多位 0 点玩家分别设置归属. 也可点击"选择/修改击飞赏归属"提前设置或修改.
6. 检查每位选手卡片的计算明细和当场总分, 保存后统计自动更新.

计算规则, `x` 为整数点数:

- 第三名名次分 = `(x - 500) / 10`.
- 第二名点数严格小于 400: 名次分 = `(x - 500) / 10`; 否则 = `(x - 400) / 10`.
- 第一名名次分 = 另外两位名次分之和的相反数.
- 第一、二名同点数且高于第三名时, 两人的名次分均为 `-第三名名次分 / 2`. chip 和击飞赏随后分别计算. 第二、三名同点数沿用上述第二、三名公式.
- chip 分 = `chip × 3`.
- 每位 0 点玩家的击飞分为 `-10`, 被指定的另一位玩家获得 `+10`.
- 基础分 = `名次分 + chip 分 + 击飞分`, 三人的基础分之和始终为 0.
- 当场总分 = `(基础分 + 额外分) × rate`.

额外分单独输入, 支持正负数, 最多两位小数. 额外分不参与基础分的零和校验. 点数、chip 的输入范围是 -1,000,000 到 1,000,000. 乘 rate 后的基础分、额外分及当场总分, 每项绝对值不超过 1,000,000.

## 多人录分与成绩表导入

在比赛卡片点击"多人录分", 或在"记一局"窗口选择"多人录分 (仅基础分和 rate)". 选择对应比赛, 添加选手并输入基础分, 填写本局统一 rate. 支持超过三人, 一局最多 200 位不同选手. 本局总分 = `基础分 × rate`, 不使用点数、chip、额外分或击飞赏.

**所有选手的基础分合计必须为 0.** 基础分最多两位小数, 页面会显示未平衡的差额并阻止保存. 上传表格、粘贴数据、后端保存和明细导入都会校验, 不通过时不会保存对局或创建选手. 使用整数单位计算, 例如 `0.1 + 0.2 - 0.3` 可以正确通过.

展开"从 Excel / CSV 批量读入", 上传仅含"选手"和"基础分"两列的 XLSX / CSV, 或直接粘贴 Excel 的两列数据. 上传表格须有这两列的标题, 粘贴时可省略标题. XLSX 读取第一张工作表, 最大 5 MB. rate 在录分窗口填写, 无需在表中填写. 读入成功后替换当前草稿, 检查本局总分再点击"保存对局". 同名选手自动复用, 新姓名在保存时建立.

保存后, 每位参与者的成绩计入所属比赛的统计和导出. 新建三人对局和多人录分时, 每位选手均有"对战数量"输入, 默认 1, 支持 0 到 1,000,000 的整数. 数量仅用于累计半庄回数及计算半庄平均得分, 不再把一条汇总成绩强行当作一场. 数量不改变分数计算, 基础分及额外分都是本条记录的合计, 不乘对战数量. 多人模式按基础分排名, 同分同名次.

批量表格可增加"对战数量"列; 缺少此列或该单元格留空时默认 1. 不带标题的粘贴数据可用第三列填写数量. 编辑、移动、备份和对局明细导入导出均保留数量; 旧数据库的每条记录自动迁移为数量 1, 不改变原有分数和 rate.

如果历史表只有每人的赛季总场数, 在"多人录分"中选择"仅汇总历史对战数量", 每人的基础分填 0, 填入各自的累计数量, 并在备注写明覆盖的历史范围. 这些数量只登记一次, 对应的逐回历史成绩填写数量 0. 数量汇总不增加成绩、走势图记录、名次或胜负. 新增的后续对局填写实际数量后, 会自然加到已登记的赛季数量上.

半庄平均得分 = 累计得分 / 半庄回数. 第一名次数只统计每位选手数量均为 1 的完整单场成绩. 对手交锋则按每条共同成绩记录判断一次胜平负, 同桌局数单独累加录入的数量. 独立的数量汇总不形成交手记录. 走势图支持个人录分顺序和全局场次两种横轴, 数量汇总不参与画图.

## 全局 rate 与旧记录

页面右上角的 `rate` 按钮用于设置新比赛的默认倍率, 新安装初始为 1. 已有数据库保留之前保存的默认倍率. rate 大于 0 且不超过 10,000, 最多两位小数. 录分窗口可单独修改本局 rate.

每场保存自己的 rate, 修改全局默认值不会重算历史比赛. 编辑一场比赛时, 显示这场原来的点数、chip、击飞赏归属、额外分及 rate, 可以重新修改并计算.

升级时, 已保存的第一、二名同点数对局会自动按平分规则修正基础分, 保留原点数、chip、击飞赏、额外分和 rate. 其余对局保留原分数. 最早的手动记录使用"手动输入基础分"模式, rate 为 1, 无需补录点数与 chip. 手动模式仍要求三人基础分相加为 0, 并支持"补齐第 3 人基础分".

最终结果最多精确至四位小数, 使用整数单位计算, 小数倍率不会引入四舍五入尾差. 排行榜、比赛记录、走势图和导出的基础分与额外分, 都使用**乘 rate 后**的分数, 保证导出总分等于同一行逐场分数之和.

例如 rate 为 5, 额外分均为 0:

| 点数 A / B / C | chip A / B / C | 击飞赏 | 最终分 A / B / C |
| --- | --- | --- | --- |
| 500 / 400 / 150 | +2 / -1 / -1 | 无 | 205 / -15 / -190 |
| 830 / 290 / 0 | 0 / 0 / 0 | B 获得 C 的 10 分 | 355 / -55 / -300 |
| 500 / 500 / 50 | 0 / 0 / 0 | 无 | 112.5 / 112.5 / -225 |

## 批量删除与人员管理

在对局记录中勾选对局, 可跨页选择, 也可全选当前比赛、日期和搜索条件下的筛选结果. 点击"删除所选对局", 确认后删除这些完整对局及所有参与者的成绩.

在选手管理中勾选人员, 点击"删除选手及关联对局". 确认窗口显示选手姓名及受影响的整场对局数量. 删除范围包含他们在全部日期的历史比赛, 同场其他玩家的该局成绩也会删除. 重叠对局只删除一次, 未关联的对局保留. 若确认期间比赛已变化, 操作会被拒绝, 不会部分删除.

批量删除无法撤销, 可用侧栏"备份数据"保存数据库. 删除后所有累计成绩重新计算. 删除全部人员后, 重启不会重新生成占位选手.

停用选手保留历史成绩, 并移出新比赛的姓名选项. 旧比赛仍可编辑. 勾选"显示已停用选手"可恢复、选中或删除停用人员. 改名自动同步到历史记录.

## 排名与走势图

排行榜按累计总分排序, 同分同名次, 未参赛选手排在末尾. 统计支持全部时间、今天、最近 7 / 30 天和自定义日期. 日期范围包含起止日期当天. 时间采用电脑本地时间.

走势图默认显示所有选手. 点击"选择选手", 勾选一位或多位后点击"生成折线图". 纵轴自动使用当前选中选手在所选比赛和日期范围内的最低、最高累计分数, 取消选手后会同步缩放; 开局及首次参赛之前的 0 分不参与范围计算, 实际成绩达到 0 分时会参与. 使用"绘图方式"选择框切换个人录分顺序和全局场次.

默认"个人录分顺序"模式按每人自己的录分记录数累计. 横轴长度取当前比赛和日期范围内所选选手的最大录分记录数. 例如最多为 6 场, 只有 3 场的人只画到第 3 场, 不补齐或延长曲线. 每条成绩记录计 1 场, 不把汇总成绩拆成未知的单场结果. 没有成绩的选手不画曲线或标记点.

"全局场次"模式按当前所选比赛和日期范围内的全部成绩记录推进, 按对局时间排序, 同一时间按记录编号排序. 每条成绩记录只算 1 场, 即使录入了 8 局也只推进 1 场. 未参赛选手在该场的累计分保持不变. 取消选手不会移除其他人的对局或改变横轴场次. 独立的历史数量汇总不推进横轴, 数量为 0 的历史成绩仍算 1 场.

折线图实际绘图区高度为 640 像素, 加上刻度与横轴标题留白后, 图表整体高度为 704 像素. 纵轴上下限只取当前所选选手、比赛和日期范围内的累计分数, 包括范围内的历史峰值与低点. 所有累计值相同时显示对应的单一刻度, 没有成绩则显示空状态.

点击得分走势右上角的"导出图片", 下载 1920 x 1080 的 PNG. 图片按当前赛季、日期范围、已选选手和绘图方式重新绘制, 含标题与选手图例, 使用白色背景和放大的刻度文字. 当前没有可绘制的成绩时, 导出按钮不可用.

每条曲线的最后一个数据点有圆形标记, 图片导出也保留标记. 悬停在标记上显示该选手在所选范围内的对局数及累计得分, 对局数按成绩记录计场, 不乘半庄回数. 个人模式只保留标记点提示; 全局模式沿横轴悬停仍显示已选选手的累计分, 并标记该场未参赛者. 当前页面保留选手选择和绘图方式, 刷新后恢复全选及个人模式. 多个页面每 5 秒同步一次; 同一场比赛被其他页面改动时, 旧版本提交会被拒绝.

## 导出与备份

Excel 的第一张"比赛统计"表和排名 CSV 使用以下栏目:

`排名 / 选手 / 第1场基础分 / 第1场额外分 / 第2场基础分 / 第2场额外分 / ... / 总分`

每人一行, 各人实际参赛按时间先后连续排列, 缺席其他对局不会留下空位. 场次数量取最多个人参赛次数, 较少者只在行末留空; 实际 0 分显示为 0. 不导出第一名次数、比例、状态、编号等内容. Excel 冻结首行与前两列, 总分有求和公式及缓存结果. CSV 为带 BOM 的 UTF-8.

导出使用所选比赛与日期范围. 导出窗口允许勾选参与排名的选手: 未勾选者仍保留全部成绩, 排在末尾, 排名显示 `-`, 其他选手重新排名. 此选项只影响导出排名, 对局明细仍保留每局所有参与者. 文件名以 `scoreboard-match-scores-` 开头.

Excel 附带第二张"对局明细"表, 用于批量导入. 每位参与者一行, 三人模式每局三行, 多人模式按实际人数记录. 包含比赛归属、时间、选手、点数、chip、名次、计分顺序、原始基础分、原始额外分、击飞赏归属和 rate. 多人模式点数与 chip 留空, 额外分为 0. 同时提供乘 rate 后的基础分、额外分与当局总分供核对. 需要 CSV 导入时, 点击"CSV 对局明细"; "CSV 比赛统计"仍是横向排名表.

## 技术统计与对手查询

在"技术统计"中通过上方比赛选择批量勾选比赛, 可以叠加日期范围. 每位选手显示半庄回数、半庄平均得分及累计得分. 没有对战数量的选手半庄平均得分显示 -, 不参与平均值计算. 页面和技术统计导出均不显示单场平均名次.

点数模式只按点数排名, 同点数同名次, 例如第一、二名同点数记为 1 / 1 / 3, 第二、三名同点数记为 1 / 2 / 2. chip、击飞赏、额外分及 rate 不改变名次或胜负; 点数相同的两人记为平局. 手动记录与多人记录未保存点数, 按当局最终得分推算名次, 同分同名次; 多人模式仅有基础分且 rate 为正, 与按基础分排名一致. 半庄平均得分 = 已选范围内个人累计最终得分 / 个人实际参赛局数. 绘图不增加局数或改变平均值.

在技术统计顶部选择赛季, 再在"对手查询"下拉框选择选手, 只列出所选赛季及日期范围内与他有共同成绩记录的对手. 未交手者不显示; 独立的半庄回数汇总不形成交手记录:

- 同桌局数累加每条共同成绩记录中双方录入场数的较小值. 双方都填 6 局时增加 6 局. 场数为 0 的历史成绩只比较录分结果, 不从赛季总数推算同桌局数.
- 同桌场数每条共同成绩记录增加 1 场. 一条记录填写 6 局时, 同桌局数增加 6, 同桌场数增加 1. 独立的数量汇总不计入这两项.
- 胜 / 平 / 负按每条成绩记录的名次比较一次, 名次更靠前视为胜, 同分记平局. 对战数量不放大胜平负: 6 局汇总中 A / B / C 得分为 +100 / -50 / -50, A 对 B、C 各增加 1 胜, B 对 C 增加 1 平.
- 胜率 = 胜 / (胜 + 平 + 负), 平局计入分母. 上述 A 对 B 为 100%, 同桌局数为 6.
- 累计分数流向表示从对手获得或付给对手的整数分数, 正数为收入, 负数为支出. A / B / C 得分为 +100 / -50 / -50 时, A 对 B、C 各记 +50, B、C 对 A 各记 -50, B 对 C 为 0. 多人对局按最终正负得分的比例分配; 先用最大余数法确定整数收支总额, 再对每笔比例份额向下或向上取整, 保证每位选手的整数总额和每笔双方收支平衡. 小数按同一规则处理; 非零和记录仅分配双方可匹配的部分.

点击"导出技术统计", Excel 包含"技术统计"、当前查询选手的"对手统计"和"统计口径"三张表. 导出范围与页面一致.

## 批量导入对局

点击"导入对局", 上传新版导出 Excel 或对局明细 CSV. 也可以下载带一局示例的 Excel 模板, 修改或删除示例三行后填写真实对局. 三人模式每局三行, 座位为 1 / 2 / 3; 多人模式每位参与者一行, 座位从 1 连续编号, 最多 200 人. 同局的比赛、时间、备注、计分方式、rate 和对局标识一致, 不同对局使用不同标识; 新录数据可填写自己编排的唯一标识, 例如 `final-round-01`. 新选手或比赛可留空选手标识、比赛标识, 按名称建立或复用.

多人模式 (`multi`) 只使用原始基础分和 rate, 基础分合计必须为 0. chip、额外分、点数和击飞赏不参与计算. 单局只导入基础分时, 使用比赛卡片中的"多人录分"入口即可, 无需填写完整对局明细格式.

可选择按表中比赛归属导入, 或全部导入到指定已有比赛. 同名选手与比赛自动复用, 新名称自动建立. 保留导出的标识可以在改名后继续识别原选手和比赛, 避免重复建立. 现有停用选手可以导入历史对局, 不会自动恢复参赛.

点数模式 (`points`) 按点数、chip、计分顺序、击飞赏归属、原始额外分和 rate 重新计算; 手动模式 (`manual`) 使用原始基础分和原始额外分. 原始分数是乘 rate 之前的值, 最多两位小数. 乘 rate 后的三列仅供核对, 修改这些派生列不会改变导入分数. 未检查点数之和是否为 1050. "名次"只按点数, 可以并列; "计分顺序"为 1 / 2 / 3, 保留第二、三名同点数时各自使用的公式. 第一、二名同点数可不填计分顺序, 系统自动平分; 第二、三名或三人同点数时需填写. 旧版没有"计分顺序"的表仍可导入, 使用其"名次"列记录的计分先后. 每位 0 点选手填写本局另一位玩家的姓名作为击飞赏归属.

点击"检查并预览", 显示新增、覆盖、跳过数量、新比赛与新选手, 并预览前 50 局最终分数. 检查不写入数据, 点击"确认导入"才一次性保存全部已检查记录. 数据或选项发生变化时需重新预览; 导入失败会完整回滚.

重复对局按导出的对局标识识别, 默认跳过. 可选择覆盖已有对局, 或作为新的对局导入. 覆盖会替换这局的时间、比赛归属和分数, 请核对预览. 一次最大 5 MB、10,000 局, 支持 XLSX 与 UTF-8 / GB18030 CSV. XLS 请另存为 XLSX. 时间格式为 `YYYY-MM-DD HH:MM` 或 `YYYY-MM-DDTHH:MM`, 也支持 Excel 日期单元格. 公式只读取已保存的缓存结果, 不执行上传的公式.

旧版横向排名表按各人参赛顺序排列, 无法确定哪些三人属于同一局, 因此不能准确还原对局. 请用新版重新导出, 或使用明细模板补录. 在 Excel 中修改文件不会直接写回程序, 需要通过导入确认保存.

正式数据在 `data/scoreboard.sqlite3`, 重启保留. "备份数据"下载包含选手、比赛及 rate 设置的完整 SQLite 文件. 恢复时先停止程序, 将原 `data` 文件夹改名留存, 新建 `data` 文件夹, 放入备份并重命名为 `scoreboard.sqlite3`, 再启动. 复制数据库文件前应先停止程序, 或使用页面备份按钮生成完整快照.

## 升级与其他参数

先停止旧程序, 保留原 `data` 文件夹. 用新版 `app.py`、`tables.py`、`static` 文件夹及两个普通启动脚本覆盖对应文件, 再启动并刷新浏览器. 也可以完整解压新版 ZIP, 再将原 `data` 文件夹复制到新版目录下. 如果旧目录有 `start-lan.bat` / `start-lan.command`, 可以删除这两个旧入口. 不要用空数据库覆盖自己的数据. 已保存的第一、二名同点数对局会自动修正分数, 其余对局保留原分数.


演示模式保存在 `data-demo`, 不要将它指向正式数据目录.
